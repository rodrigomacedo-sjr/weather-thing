# TOP Weather App

Part of [The Odin Project's](https://www.theodinproject.com) JavaScript course.
The goal is to work with asynchronous code using Promisses and `async`/`await`.

## Assignment
- [x] Setup boilerplate
- [x] Write functions that hit the api
- [x] Write function that process the data from the API into an object
- [x] Set up a form for users to input their location
- [x] Display the info on the webpage
- [x] Display weather icons
- [x] Add basic styling
- [ ] Add a not found component
- [ ] Add a loading component
- [ ] Publish on GH
